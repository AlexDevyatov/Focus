# Assets Directory

Эта папка предназначена для хранения TensorFlow Lite моделей.

## Требования

Для работы приложения необходимо добавить TFLite модель в эту папку с именем `model.tflite`.

Модель должна быть обучена для обработки изображений и поддерживать следующие входные/выходные форматы:
- Вход: изображение (RGB)
- Выход: обработанное изображение (RGB)

## Пример структуры

```
assets/
  └── model.tflite
```

## Примечание

Если модель не найдена, приложение выдаст ошибку при инициализации. 
Убедитесь, что модель находится в правильной папке перед запуском приложения.
