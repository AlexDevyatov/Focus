# Neural Photo Redactor

Android приложение для обработки изображений с использованием нейросетевых моделей TensorFlow Lite. Приложение позволяет применять различные фильтры, редактировать изображения и сохранять историю обработки.

## 🚀 Основные возможности

- **Обработка изображений**: Применение различных фильтров и эффектов
- **Нейросетевые фильтры**: Использование TensorFlow Lite моделей для улучшения качества изображений
- **Редактирование**: Корректировка яркости, контраста, цветового баланса
- **Геометрические операции**: Обрезка, поворот, отражение изображений
- **История обработки**: Сохранение всех примененных операций с возможностью просмотра деталей
- **Галерея**: Просмотр и выбор изображений из галереи устройства
- **Material Design 3**: Современный и интуитивный пользовательский интерфейс

## 🏗️ Архитектура

Проект использует **Clean Architecture** с разделением на слои:

```
app/
├── ui/              # Презентационный слой (Jetpack Compose + M3)
├── domain/          # Бизнес-логика (UseCases, Models, Repositories)
├── data/            # Слой данных (Repositories, DAO, Storage)
└── ml/              # ML слой (TensorFlow Lite, обработка изображений)
```

### Технологический стек

- **UI**: Jetpack Compose, Material Design 3
- **Архитектура**: MVVM, Clean Architecture
- **Dependency Injection**: Hilt
- **База данных**: Room Database
- **ML**: TensorFlow Lite
- **Язык**: Kotlin
- **Минимальная версия Android**: API 29 (Android 10)
- **Целевая версия**: API 36 (Android 15)

## 📦 Установка

### Требования

- Android Studio Hedgehog или новее
- JDK 11 или выше
- Android SDK (API 29+)
- Gradle 8.0+

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd NeuralPhotoRedactor
```

2. Откройте проект в Android Studio

3. Дождитесь синхронизации Gradle и загрузки зависимостей

4. Подключите Android устройство или запустите эмулятор

5. Запустите приложение (Run → Run 'app')

## 🎯 Использование

### Основные экраны

- **Галерея**: Выбор изображения из галереи устройства
- **Редактор**: Применение фильтров и редактирование изображений
- **AI Фильтры**: Применение нейросетевых фильтров (улучшение качества, стилизация)
- **История**: Просмотр всех обработанных изображений с деталями операций
- **Обработанные изображения**: Галерея сохраненных результатов

### Применение фильтров

1. Выберите изображение из галереи
2. Перейдите в редактор
3. Выберите фильтр или операцию редактирования
4. Настройте параметры (интенсивность, значения)
5. Сохраните результат

### Нейросетевые фильтры

Приложение поддерживает следующие ML-модели:
- **Upscale**: Увеличение разрешения изображения
- **Denoise**: Удаление шумов
- **Style Transfer**: Перенос стиля (AnimeGAN2, Hayao, CelebA и др.)

```
│   ├── ui/              # UI компоненты и экраны

│   │   ├── components/  # Переиспользуемые компоненты

│   │   └── theme/       # Тема приложения

│   │   ├── interpreter/   # TensorFlow Lite процессоры
│   │   ├── filter/      # Фильтры изображений
│   │   └── edit/        # Редактирование изображений
│   └── di/              # Dependency Injection модули
└── assets/              # TensorFlow Lite модели (.tflite)
```
