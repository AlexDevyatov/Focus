## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Полное наименование системы

Автоматизированная система обработки изображений "Focus" (Neural Photo Redactor) — мобильное приложение для Android для обработки фотографий с использованием нейросетевых моделей TensorFlow Lite и классических алгоритмов.

### 1.2. Краткая характеристика области применения

Система предназначена для обработки фотографий, применения художественных фильтров, улучшения качества изображений (увеличение разрешения, удаление шумов), стилизации и редактирования изображений.

### 1.3. Перечень принятых сокращений

- **ML** — Machine Learning
- **TFLite** — TensorFlow Lite
- **AGSL** — Android Graphics Shading Language
- **GPU** — Graphics Processing Unit

## 2. НАЗНАЧЕНИЕ И ОБЛАСТЬ ПРИМЕНЕНИЯ

### 2.1. Назначение системы

Система предназначена для обработки цифровых изображений на Android с использованием:
- Классических алгоритмов (размытие, резкость, виньетка, сепия, черно-белое)
- Нейросетевых моделей TensorFlow Lite (улучшение качества, стилизация)
- Инструментов редактирования (кадрирование, поворот, коррекция цветов)

### 2.2. Область применения

Обработка фотографий с камеры, редактирование изображений из галереи, применение художественных эффектов, улучшение качества и стилизация изображений.

### 2.3. Требования к пользователю

Умение работать с Android-устройством и понимание основ работы с приложениями и фотографиями.

## 3. ОПИСАНИЕ ФУНКЦИЙ

### 3.1. Общие сведения

Система предоставляет функции: выбор изображений из галереи, съемка фотографий, применение классических и AI-фильтров, редактирование изображений, сохранение результатов, просмотр истории обработки.

### 3.2. Функция выбора изображений

**Назначение:** Выбор изображения из галереи для обработки.

**Условия:** Android 10+ (API 29), разрешение на доступ к медиафайлам.

**Описание:** При первом открытии система запрашивает разрешение. После предоставления отображается сетка изображений. Обновление списка — pull-to-refresh. Нажатие на изображение открывает редактор.

**Результат:** Открыт экран редактора с выбранным изображением.

### 3.3. Функция съемки фотографий

**Назначение:** Съемка фотографии камерой устройства.

**Условия:** Android 10+, разрешение на использование камеры, наличие камеры.

**Описание:** При нажатии "Камера" запрашивается разрешение. После предоставления открывается камера. Сделанная фотография автоматически открывается в редакторе.

**Результат:** Открыт редактор с фотографией.

### 3.4. Функция применения классических фильтров

**Назначение:** Применение классических фильтров обработки.

**Доступные фильтры:**
- Размытие (Gaussian Blur) — настройка интенсивности 0-100%
- Резкость (Sharpen) — настройка интенсивности 0-100%
- Виньетка (Vignette) — настройка интенсивности 0-100%
- Черно-белое (Grayscale) — без настройки
- Сепия (Sepia) — без настройки

**Описание:** В режиме "Фильтры" отображаются иконки фильтров. Нажатие применяет фильтр. Для некоторых фильтров доступна настройка интенсивности слайдером. Можно применять несколько фильтров одновременно. Результат отображается в реальном времени.

**Результат:** К изображению применен фильтр с заданной интенсивностью.

### 3.5. Функция применения AI-фильтров

**Назначение:** Применение нейросетевых фильтров на основе TensorFlow Lite.

**Доступные AI-фильтры:**
- Суперразрешение (Upscale) — увеличение разрешения
- Умное шумоподавление (Denoise) — удаление шумов
- Художественный стиль (Style Transfer) — AnimeGAN Face Paint, CelebA Distill, Hayao

**Описание:** Кнопка "ИИ" на главном экране открывает экран AI-фильтров. Выбирается изображение и фильтр. Обработка выполняется оффлайн на устройстве. Во время обработки отображается индикатор прогресса. После обработки открывается экран предпросмотра с возможностью сравнения.

**Результат:** Изображение обработано с использованием выбранного AI-фильтра.

### 3.6. Функция редактирования изображений

**Назначение:** Редактирование изображения: настройка цветовых параметров и геометрические преобразования.

**Доступные операции:**
- **Цвет:** Яркость (-100% до +100%), Контраст (-100% до +100%), Цветовой баланс (красный, зеленый, синий: -100% до +100%)
- **Геометрия:** Кадрирование, Поворот (90°, 180°, 270°), Отражение по горизонтали

**Описание:** В режиме "Настройки" отображаются иконки операций. Для цветовых операций доступна настройка слайдером. Для кадрирования открывается оверлей выбора области. Поворот и отражение применяются сразу. Все изменения отображаются в реальном времени.

**Результат:** Изображение отредактировано в соответствии с выбранными параметрами.

### 3.7. Функция сохранения и просмотра истории

**Назначение:** Сохранение обработанных изображений и просмотр истории обработки.

**Описание:** Кнопка "Сохранить" в редакторе сохраняет изображение в галерею и создает запись в истории. Кнопка "История" на главном экране открывает список обработанных изображений с деталями примененных операций. При нажатии на запись открывается детальная информация. Из детального просмотра можно перейти к редактированию.

**Результат:** Изображение сохранено, история обработки доступна для просмотра.

## 4. ОПИСАНИЕ ОПЕРАЦИЙ

### 4.1. Операция "Выбор изображения из галереи"

1. Запустить приложение "Focus"
2. Нажать кнопку "Галерея"
3. При необходимости предоставить разрешение на доступ к медиафайлам
4. Выбрать изображение из сетки

**Результат:** Открыт редактор с выбранным изображением.

### 4.2. Операция "Съемка фотографии"

1. На главном экране нажать кнопку "Камера"
2. При необходимости предоставить разрешение на использование камеры
3. Сделать фотографию
4. Дождаться открытия редактора

**Результат:** Открыт редактор с фотографией.

### 4.3. Операция "Применение классического фильтра"

1. Открыть изображение в редакторе
2. Убедиться, что активен режим "Фильтры"
3. Нажать на иконку нужного фильтра
4. Для фильтров с настройкой использовать слайдер (0-100%)
5. При необходимости применить дополнительные фильтры
6. Нажать "Сохранить" для сохранения результата

**Результат:** К изображению применен фильтр.

### 4.4. Операция "Применение AI-фильтра"

1. На главном экране нажать кнопку "ИИ"
2. Выбрать изображение из галереи или сделать фотографию
3. Выбрать AI-фильтр
4. Дождаться завершения обработки
5. На экране предпросмотра нажать "Сохранить" или "Отмена"

**Результат:** Изображение обработано с использованием AI-фильтра.

### 4.5. Операция "Редактирование изображения"

1. Открыть изображение в редакторе
2. Переключиться в режим "Настройки"
3. Выбрать операцию редактирования:
   - **Цвет:** Нажать иконку (Яркость/Контраст/Цветовой баланс), использовать слайдер
   - **Кадрирование:** Нажать иконку кадрирования, выбрать область, нажать "Применить"
   - **Поворот/Отражение:** Нажать соответствующую иконку
4. Нажать "Сохранить" для сохранения результата

**Результат:** Изображение отредактировано.

### 4.6. Операция "Просмотр истории обработки"

1. На главном экране нажать кнопку "История"
2. Просмотреть список обработанных изображений
3. При необходимости нажать на запись для просмотра деталей
4. Для повторного редактирования нажать "Редактировать"

**Результат:** Отображена история обработки.

## 5. СООБЩЕНИЯ ОПЕРАТОРУ

### 5.1. Информационные сообщения

**"Изображение сохранено"** — отображается после успешного сохранения. Дополнительных действий не требуется.

**Индикатор загрузки** — отображается во время загрузки изображений или обработки. Дождаться завершения операции.

### 5.2. Сообщения об ошибках

**"Ошибка загрузки изображений"** — причины: отсутствие разрешения, проблемы с доступом, отсутствие изображений. Действия: проверить разрешение, предоставить при необходимости, повторить попытку.

**"Ошибка при съемке фотографии"** — причины: отсутствие разрешения, камера занята, проблемы с камерой. Действия: проверить разрешение, закрыть другие приложения, проверить камеру.

**"Ошибка обработки изображения"** — причины: недостаточно памяти, проблемы с моделью, поврежденное изображение. Действия: освободить память, закрыть другие приложения, попробовать другое изображение.

**"Ошибка загрузки истории"** — причины: проблемы с базой данных, недостаточно памяти. Действия: перезапустить приложение, освободить память.

### 5.3. Диалоговые окна запроса разрешений

**Запрос разрешения на доступ к медиафайлам** — появляется при первом открытии галереи. Нажать "Предоставить разрешение" или "Отмена".

**Запрос разрешения на использование камеры** — появляется при нажатии "Камера". Нажать "Предоставить разрешение" или "Отмена".

### 5.4. Сообщения о пустых состояниях

**"История пуста"** — отображается при отсутствии записей в истории. Обработать и сохранить изображение.

**"Нет обработанных изображений"** — отображается при отсутствии сохраненных изображений. Обработать и сохранить изображение.

## 6. ПРИЛОЖЕНИЯ

### 6.1. Приложение А. Системные требования

**Минимальные требования:**
- Android 10 (API 29) или выше
- Оперативная память: не менее 2 ГБ
- Свободное место: не менее 100 МБ
- Камера: опционально

**Рекомендуемые требования:**
- Android 12 (API 31) или выше
- Оперативная память: не менее 4 ГБ
- Свободное место: не менее 200 МБ
- GPU: поддержка OpenGL ES 3.0+

### 6.2. Приложение Б. Список фильтров и операций

**Классические фильтры:**
- Размытие, Резкость, Виньетка (настройка 0-100%)
- Черно-белое, Сепия (без настройки)

**AI-фильтры:**
- Суперразрешение (ESRGAN)
- Умное шумоподавление (SplitterNet)
- Художественный стиль (AnimeGAN2, AnimeGAN Face Paint, CelebA Distill, Hayao)

**Операции редактирования:**
- Яркость, Контраст, Цветовой баланс (-100% до +100%)
- Кадрирование, Поворот (90°/180°/270°), Отражение

### 6.3. Приложение В. Структура экранов

**Главный экран:** Логотип, кнопки "Галерея", "ИИ", "Камера", "История"

**Экран галереи:** Сетка изображений, индикатор загрузки, сообщения об ошибках

**Экран редактора:** Область изображения, иконки фильтров/операций, слайдеры, кнопки переключения режимов

**Экран AI-фильтров:** Карточки с описанием AI-фильтров

**Экран предпросмотра AI:** Обработанное изображение, кнопки "Сохранить"/"Отмена", "Сравнить", "Поделиться"

**Экран истории:** Список обработанных изображений, bottom sheet с деталями

### 6.4. Приложение Г. FAQ

**Вопрос 1:** Почему не загружаются изображения из галереи?  
**Ответ:** Проверьте разрешение на доступ к медиафайлам. Разрешение запрашивается автоматически.

**Вопрос 2:** Почему обработка AI-фильтром занимает много времени?  
**Ответ:** Обработка требует значительных ресурсов. Время зависит от размера изображения и производительности устройства.

**Вопрос 3:** Можно ли отменить примененный фильтр?  
**Ответ:** Да, нажмите на иконку фильтра повторно. Отмена применяется только к последнему фильтру.

**Вопрос 4:** Сохраняется ли история при переустановке?  
**Ответ:** Нет, история хранится локально и удаляется при удалении приложения. Обработанные изображения сохраняются в галерею.

**Вопрос 5:** Работают ли AI-фильтры оффлайн?  
**Ответ:** Да, все AI-фильтры работают полностью оффлайн на устройстве.

**Вопрос 6:** Какие форматы изображений поддерживаются?  
**Ответ:** JPEG, PNG, WebP и другие стандартные форматы Android.
