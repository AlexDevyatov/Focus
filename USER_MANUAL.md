# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ
## Автоматизированная система обработки изображений "Focus"

**Версия:** 1.0 | **Дата:** 2024 | **Соответствие:** РД 50-34.698-90

---

## 1. ОБЩИЕ СВЕДЕНИЯ

**Назначение:** Мобильное приложение для Android для обработки фотографий с использованием нейросетевых моделей TensorFlow Lite и классических алгоритмов.

**Область применения:** Обработка фотографий, применение фильтров и эффектов, улучшение качества изображений, стилизация, редактирование (кадрирование, поворот, коррекция цветов).

**Требования:** Android 10+ (API 29), 2 ГБ ОЗУ, 100 МБ свободного места. Рекомендуется: Android 12+, 4 ГБ ОЗУ, 200 МБ.

---

## 2. ОПИСАНИЕ ФУНКЦИЙ

**Основные функции:**
- Выбор изображений из галереи (требуется разрешение на доступ к медиафайлам)
- Съемка фотографий камерой (требуется разрешение на использование камеры)
- Применение классических фильтров: Размытие, Резкость, Виньетка (настройка 0-100%), Черно-белое, Сепия
- Применение AI-фильтров: Суперразрешение (ESRGAN), Умное шумоподавление (SplitterNet), Художественный стиль (AnimeGAN2, Face Paint, CelebA Distill, Hayao)
- Редактирование: Яркость, Контраст, Цветовой баланс (-100% до +100%), Кадрирование, Поворот (90°/180°/270°), Отражение
- Сохранение обработанных изображений в галерею
- Просмотр истории обработки с деталями примененных операций

---

## 3. ОПИСАНИЕ ОПЕРАЦИЙ

### 3.1. Выбор изображения из галереи
1. Запустить приложение → "Галерея"
2. Предоставить разрешение (при запросе)
3. Выбрать изображение из сетки

### 3.2. Съемка фотографии
1. На главном экране → "Камера"
2. Предоставить разрешение (при запросе)
3. Сделать фотографию

### 3.3. Применение классического фильтра
1. Открыть изображение в редакторе
2. Режим "Фильтры" → выбрать фильтр
3. Настроить интенсивность слайдером (для Размытие/Резкость/Виньетка)
4. "Сохранить"

### 3.4. Применение AI-фильтра
1. Главный экран → "ИИ"
2. Выбрать изображение или сделать фотографию
3. Выбрать AI-фильтр
4. Дождаться обработки
5. "Сохранить" или "Отмена"

### 3.5. Редактирование изображения
1. Открыть изображение в редакторе
2. Режим "Настройки" → выбрать операцию:
   - **Цвет:** Яркость/Контраст/Цветовой баланс → слайдер
   - **Кадрирование:** Выбрать область → "Применить"
   - **Поворот/Отражение:** Нажать иконку
3. "Сохранить"

### 3.6. Просмотр истории
1. Главный экран → "История"
2. Просмотреть список → при необходимости открыть детали
3. "Редактировать" для повторного редактирования

## 4. СООБЩЕНИЯ ОПЕРАТОРУ

**Информационные:**
- "Изображение сохранено" — успешное сохранение
- Индикатор загрузки — ожидание завершения операции

**Ошибки:**
- "Ошибка загрузки изображений" — проверить разрешение, повторить попытку
- "Ошибка при съемке фотографии" — проверить разрешение, закрыть другие приложения
- "Ошибка обработки изображения" — освободить память, попробовать другое изображение
- "Ошибка загрузки истории" — перезапустить приложение

**Диалоги разрешений:**
- Доступ к медиафайлам — "Предоставить разрешение"
- Использование камеры — "Предоставить разрешение"

**Пустые состояния:**
- "История пуста" / "Нет обработанных изображений" — обработать и сохранить изображение

## 5. ПРИЛОЖЕНИЯ

### 5.1. Системные требования
**Минимум:** Android 10+, 2 ГБ ОЗУ, 100 МБ  
**Рекомендуется:** Android 12+, 4 ГБ ОЗУ, 200 МБ, GPU с OpenGL ES 3.0+

### 5.2. Доступные фильтры и операции
**Классические:** Размытие, Резкость, Виньетка (0-100%), Черно-белое, Сепия  
**AI:** Суперразрешение, Шумоподавление, Художественный стиль (4 варианта)  
**Редактирование:** Яркость, Контраст, Цветовой баланс, Кадрирование, Поворот, Отражение

### 5.3. FAQ
**Q:** Не загружаются изображения?  
**A:** Проверить разрешение на доступ к медиафайлам.

**Q:** Долгая обработка AI-фильтром?  
**A:** Нормально, зависит от размера изображения и производительности устройства.

**Q:** Можно отменить фильтр?  
**A:** Да, нажать на иконку фильтра повторно (отменяется только последний).

**Q:** История сохраняется при переустановке?  
**A:** Нет, только обработанные изображения в галерее остаются.

**Q:** AI-фильтры работают оффлайн?  
**A:** Да, все операции выполняются локально на устройстве.

**Q:** Какие форматы поддерживаются?  
**A:** JPEG, PNG, WebP и другие стандартные форматы Android.
