## 1. ОБЩИЕ СВЕДЕНИЯ

### 1.1. Полное наименование системы

Автоматизированная система обработки изображений "Focus" (Neural Photo Redactor) — мобильное приложение для Android, предназначенное для обработки фотографий с использованием нейросетевых моделей TensorFlow Lite и классических алгоритмов обработки изображений.

### 1.2. Краткая характеристика области применения

Система предназначена для:
- Обработки фотографий на мобильных устройствах Android
- Применения художественных фильтров и эффектов
- Улучшения качества изображений (увеличение разрешения, удаление шумов)
- Стилизации изображений с использованием нейросетевых моделей
- Редактирования изображений (кадрирование, поворот, коррекция цветов)
- Сохранения истории обработки для последующего просмотра и редактирования

### 1.3. Сведения о разработчике

Разработано в соответствии с требованиями Clean Architecture и Material Design 3.

### 1.4. Перечень документов, на которые даны ссылки в руководстве

## 2. НАЗНАЧЕНИЕ И ОБЛАСТЬ ПРИМЕНЕНИЯ

### 2.1. Назначение системы

Система "Focus" предназначена для обработки цифровых изображений на мобильных устройствах Android с использованием:
- Классических алгоритмов обработки изображений (размытие, резкость, виньетка, сепия, черно-белое)
- Нейросетевых моделей TensorFlow Lite для улучшения качества и стилизации изображений
- Инструментов редактирования (кадрирование, поворот, отражение, коррекция яркости, контраста, цветового баланса)

### 2.2. Область применения

Система применяется для:
- Обработки фотографий, сделанных камерой устройства
- Редактирования изображений из галереи устройства
- Применения художественных эффектов и фильтров
- Улучшения качества изображений (увеличение разрешения, удаление шумов)
- Стилизации изображений в различных художественных стилях

### 2.3. Характеристика пользователей

Система предназначена для пользователей мобильных устройств Android версии 10 (API 29) и выше, желающих обрабатывать и редактировать фотографии на своем устройстве.

### 2.4. Требования к квалификации пользователя

Для работы с системой пользователь должен:
- Уметь работать с мобильным устройством на базе Android
- Понимать основные принципы работы с приложениями Android
- Знать основы работы с фотографиями и изображениями

## 3. ОПИСАНИЕ ФУНКЦИЙ

### 3.1. Общие сведения о функциях системы

Система предоставляет следующие основные функции:
1. Выбор изображений из галереи устройства
2. Съемка фотографий с помощью камеры устройства
3. Применение классических фильтров обработки изображений
4. Применение нейросетевых фильтров (AI-фильтры)
5. Редактирование изображений (настройки цвета, геометрия)
6. Сохранение обработанных изображений
7. Просмотр истории обработки
8. Просмотр обработанных изображений

### 3.2. Функция выбора изображений

**Назначение:** Позволяет пользователю выбрать изображение из галереи устройства для последующей обработки.

**Условия выполнения:**
- На устройстве установлена версия Android 10 (API 29) или выше
- Предоставлено разрешение на доступ к медиафайлам (для Android 13+) или к хранилищу (для более ранних версий)

**Описание:**
- При первом открытии экрана галереи система автоматически запрашивает необходимое разрешение
- После предоставления разрешения отображается сетка всех изображений из галереи устройства
- Пользователь может обновить список изображений, потянув экран вниз (pull-to-refresh)
- При нажатии на изображение происходит переход к экрану редактора

**Результат:** Выбрано изображение для обработки, открыт экран редактора.

### 3.3. Функция съемки фотографий

**Назначение:** Позволяет пользователю сделать фотографию с помощью камеры устройства для последующей обработки.

**Условия выполнения:**
- На устройстве установлена версия Android 10 (API 29) или выше
- Предоставлено разрешение на использование камеры
- Устройство оснащено камерой

**Описание:**
- При нажатии на кнопку "Камера" система запрашивает разрешение на использование камеры (если оно не предоставлено)
- После предоставления разрешения открывается стандартное приложение камеры Android
- Пользователь делает фотографию
- Сделанная фотография автоматически открывается в редакторе

**Результат:** Сделана фотография, открыт экран редактора с загруженным изображением.

### 3.4. Функция применения классических фильтров

**Назначение:** Позволяет применять к изображению классические фильтры обработки.

**Доступные фильтры:**
1. **Размытие (Gaussian Blur)** — создает эффект размытия изображения
2. **Резкость (Sharpen)** — увеличивает четкость изображения
3. **Виньетка (Vignette)** — затемняет края изображения
4. **Черно-белое (Grayscale)** — преобразует изображение в оттенки серого
5. **Сепия (Sepia)** — применяет сепийный эффект (коричневатый оттенок)

**Описание:**
- На экране редактора в режиме "Фильтры" отображаются иконки доступных фильтров
- Пользователь нажимает на иконку фильтра для его применения
- Для фильтров "Размытие", "Резкость" и "Виньетка" доступна настройка интенсивности с помощью слайдера (от 0 до 100%)
- Фильтры "Черно-белое" и "Сепия" применяются без настройки интенсивности
- Можно применять несколько фильтров одновременно
- Результат обработки отображается в реальном времени

**Результат:** К изображению применен выбранный фильтр с заданной интенсивностью.

### 3.5. Функция применения нейросетевых фильтров (AI-фильтры)

**Назначение:** Позволяет применять к изображению нейросетевые фильтры на основе моделей TensorFlow Lite.

**Доступные AI-фильтры:**
1. **Суперразрешение (Upscale)** — увеличивает разрешение изображения с сохранением качества
2. **Умное шумоподавление (Denoise)** — удаляет шумы с изображения с использованием нейросети
3. **Художественный стиль (Style Transfer)** — применяет различные художественные стили:
   - AnimeGAN Face Paint
   - CelebA Distill
   - Hayao

**Описание:**
- На главном экране нажимается кнопка "ИИ" для перехода к экрану AI-фильтров
- На экране AI-фильтров отображаются карточки с описанием каждого фильтра
- Пользователь выбирает изображение из галереи или делает фотографию
- Выбирается нужный AI-фильтр
- Обработка выполняется на устройстве с использованием TensorFlow Lite (оффлайн)
- Во время обработки отображается индикатор прогресса
- После обработки открывается экран предпросмотра с возможностью сравнения исходного и обработанного изображения

**Результат:** Изображение обработано с использованием выбранного нейросетевого фильтра.

### 3.6. Функция редактирования изображений

**Назначение:** Позволяет редактировать изображение: настраивать цветовые параметры и выполнять геометрические преобразования.

**Доступные операции редактирования:**

#### 3.6.1. Настройки цвета
- **Яркость (Brightness)** — регулировка яркости изображения (диапазон: -100% до +100%)
- **Контраст (Contrast)** — регулировка контрастности изображения (диапазон: -100% до +100%)
- **Цветовой баланс (Color Balance)** — настройка баланса цветовых каналов:
  - Красный канал (диапазон: -100% до +100%)
  - Зеленый канал (диапазон: -100% до +100%)
  - Синий канал (диапазон: -100% до +100%)

#### 3.6.2. Геометрические операции
- **Кадрирование (Crop)** — обрезка изображения по выбранной области
- **Поворот на 90°** — поворот изображения на 90 градусов по часовой стрелке
- **Поворот на 180°** — поворот изображения на 180 градусов
- **Поворот на 270°** — поворот изображения на 270 градусов (или -90°)
- **Отражение по горизонтали (Flip Horizontal)** — зеркальное отражение изображения по горизонтали

**Описание:**
- На экране редактора переключается режим на "Настройки"
- Отображаются иконки доступных операций редактирования
- Для операций "Яркость", "Контраст" и "Цветовой баланс" доступна настройка с помощью слайдера
- Для операции "Кадрирование" открывается оверлей с возможностью выбора области обрезки
- Для операций поворота и отражения результат применяется сразу после нажатия
- Все изменения отображаются в реальном времени

**Результат:** Изображение отредактировано в соответствии с выбранными параметрами.

### 3.7. Функция сохранения обработанных изображений

**Назначение:** Позволяет сохранить обработанное изображение в галерею устройства.

**Описание:**
- На экране редактора в верхней панели отображается кнопка "Сохранить" (иконка сохранения)
- При нажатии на кнопку обработанное изображение сохраняется в галерею устройства
- Система автоматически создает запись в истории обработки с информацией о примененных фильтрах и операциях редактирования
- После сохранения отображается уведомление "Изображение сохранено"

**Результат:** Обработанное изображение сохранено в галерею устройства, создана запись в истории обработки.

### 3.8. Функция просмотра истории обработки

**Назначение:** Позволяет просматривать историю всех обработанных изображений с деталями примененных операций.

**Описание:**
- На главном экране нажимается кнопка "История"
- Отображается список всех обработанных изображений в хронологическом порядке (новые сверху)
- Каждая запись содержит:
  - Миниатюру обработанного изображения
  - Дату и время обработки
  - Список примененных фильтров
  - Список примененных операций редактирования
- При нажатии на запись открывается детальная информация в виде bottom sheet
- Из детального просмотра можно перейти к редактированию изображения (кнопка "Редактировать")

**Результат:** Отображена история обработки с возможностью просмотра деталей и повторного редактирования.

### 3.9. Функция просмотра обработанных изображений

**Назначение:** Позволяет просматривать все сохраненные обработанные изображения.

**Описание:**
- Функция доступна через экран истории обработки
- Отображается сетка всех обработанных изображений
- При нажатии на изображение открывается детальная информация

**Результат:** Отображены все обработанные изображения.

## 4. ОПИСАНИЕ ОПЕРАЦИЙ

### 4.1. Общие сведения

В данном разделе описываются последовательности действий пользователя для выполнения основных операций в системе.

### 4.2. Операция "Выбор изображения из галереи"

**Цель:** Выбрать изображение из галереи устройства для обработки.

**Последовательность действий:**
1. Запустить приложение "Focus"
2. На главном экране нажать кнопку "Галерея"
3. Если разрешение на доступ к медиафайлам не предоставлено:
   - Система автоматически запросит разрешение
   - Нажать "Разрешить" в диалоговом окне
4. Дождаться загрузки списка изображений
5. При необходимости обновить список, потянув экран вниз
6. Нажать на нужное изображение

**Результат:** Открыт экран редактора с выбранным изображением.

**Примечания:**
- Если разрешение не предоставлено, список изображений не отобразится
- Для обновления списка можно использовать жесты pull-to-refresh

### 4.3. Операция "Съемка фотографии"

**Цель:** Сделать фотографию с помощью камеры устройства для обработки.

**Последовательность действий:**
1. Запустить приложение "Focus"
2. На главном экране нажать кнопку "Камера" (иконка камеры)
3. Если разрешение на использование камеры не предоставлено:
   - Система автоматически запросит разрешение
   - Нажать "Разрешить" в диалоговом окне
4. Дождаться открытия приложения камеры
5. Навести камеру на объект съемки
6. Нажать кнопку съемки в приложении камеры
7. Дождаться обработки фотографии

**Результат:** Открыт экран редактора с сделанной фотографией.

**Примечания:**
- Если разрешение не предоставлено, камера не откроется
- После съемки фотография автоматически открывается в редакторе

### 4.4. Операция "Применение классического фильтра"

**Цель:** Применить к изображению классический фильтр обработки.

**Последовательность действий:**
1. Открыть изображение в редакторе (см. операции 4.2 или 4.3)
2. Убедиться, что активен режим "Фильтры" (кнопка "Фильтры" должна быть выделена)
3. Нажать на иконку нужного фильтра:
   - Размытие (иконка размытия)
   - Резкость (иконка резкости)
   - Виньетка (иконка виньетки)
   - Черно-белое (иконка черно-белого)
   - Сепия (иконка сепии)
4. Для фильтров "Размытие", "Резкость" и "Виньетка":
   - Использовать слайдер для настройки интенсивности (от 0 до 100%)
   - Наблюдать изменения в реальном времени
5. При необходимости применить дополнительные фильтры (повторить шаги 3-4)
6. Для сохранения результата нажать кнопку "Сохранить" в верхней панели

**Результат:** К изображению применен выбранный фильтр с заданной интенсивностью.

**Примечания:**
- Фильтры "Черно-белое" и "Сепия" применяются без настройки интенсивности
- Можно применять несколько фильтров одновременно
- Изменения отображаются в реальном времени

### 4.5. Операция "Применение AI-фильтра"

**Цель:** Применить к изображению нейросетевой фильтр.

**Последовательность действий:**
1. Запустить приложение "Focus"
2. На главном экране нажать кнопку "ИИ"
3. Выбрать изображение из галереи или сделать фотографию:
   - Нажать кнопку выбора изображения
   - Выбрать изображение из галереи (см. операцию 4.2)
   - Или нажать кнопку камеры и сделать фотографию (см. операцию 4.3)
4. На экране AI-фильтров выбрать нужный фильтр:
   - Суперразрешение
   - Умное шумоподавление
   - Художественный стиль (AnimeGAN Face Paint, CelebA Distill, Hayao)
5. Дождаться завершения обработки (отображается индикатор прогресса)
6. На экране предпросмотра:
   - Просмотреть обработанное изображение
   - При необходимости сравнить с исходным (кнопка "Сравнить")
   - Нажать кнопку "Сохранить" для сохранения результата
   - Или нажать кнопку "Отмена" для возврата

**Результат:** Изображение обработано с использованием выбранного AI-фильтра и сохранено (при выборе "Сохранить").

**Примечания:**
- Обработка AI-фильтрами может занять некоторое время в зависимости от размера изображения и производительности устройства
- Все AI-фильтры работают оффлайн, без подключения к интернету
- На экране предпросмотра можно поделиться изображением через другие приложения

### 4.6. Операция "Редактирование яркости и контраста"

**Цель:** Настроить яркость и контрастность изображения.

**Последовательность действий:**
1. Открыть изображение в редакторе (см. операции 4.2 или 4.3)
2. Переключиться в режим "Настройки" (нажать кнопку "Настройки")
3. Нажать на иконку "Яркость"
4. Использовать слайдер для настройки яркости:
   - Переместить слайдер влево для уменьшения яркости (до -100%)
   - Переместить слайдер вправо для увеличения яркости (до +100%)
   - Наблюдать изменения в реальном времени
5. Нажать на иконку "Контраст"
6. Использовать слайдер для настройки контрастности:
   - Переместить слайдер влево для уменьшения контраста (до -100%)
   - Переместить слайдер вправо для увеличения контраста (до +100%)
   - Наблюдать изменения в реальном времени
7. Для сохранения результата нажать кнопку "Сохранить" в верхней панели

**Результат:** Яркость и контрастность изображения настроены в соответствии с выбранными значениями.

**Примечания:**
- Изменения отображаются в реальном времени

## 6. ПРИЛОЖЕНИЯ

### 6.1. Приложение А. Глоссарий терминов

**Автоматизированная система** — комплекс программных и технических средств, предназначенный для автоматизации процессов обработки данных.

**AI-фильтр** — фильтр обработки изображений, использующий технологии машинного обучения (нейросети) для улучшения качества или стилизации изображений.

**Bitmap** — растровое изображение, представленное в виде массива пикселей.

**GPU** — Graphics Processing Unit, графический процессор, используемый для ускорения обработки изображений.

**TensorFlow Lite** — фреймворк для выполнения моделей машинного обучения на мобильных устройствах.

**AGSL** — Android Graphics Shading Language, язык шейдеров для создания графических эффектов на Android.

**Модель машинного обучения** — файл, содержащий обученную нейросеть для выполнения определенных задач (например, увеличение разрешения, удаление шумов).

**Оффлайн** — работа без подключения к интернету, все операции выполняются локально на устройстве.

**Pull-to-refresh** — жест обновления содержимого экрана путем потягивания вниз.

**Bottom sheet** — элемент интерфейса, отображающийся в нижней части экрана с дополнительной информацией.

| Художественный стиль (Style Transfer) | Применяет художественные стили | AnimeGAN2, AnimeGAN Face Paint, CelebA Distill, Hayao |

### 6.5. Приложение Д. Часто задаваемые вопросы (FAQ)

**Вопрос 1:** Почему не загружаются изображения из галереи?

**Ответ:** Убедитесь, что предоставлено разрешение на доступ к медиафайлам. Для Android 13+ требуется разрешение READ_MEDIA_IMAGES, для более ранних версий — READ_EXTERNAL_STORAGE. Разрешение запрашивается автоматически при первом открытии экрана галереи.

**Вопрос 2:** Почему обработка AI-фильтром занимает много времени?

**Ответ:** Обработка AI-фильтрами требует значительных вычислительных ресурсов. Время обработки зависит от размера изображения и производительности устройства. Для ускорения обработки рекомендуется закрыть другие приложения и использовать устройство с более мощным процессором.

**Вопрос 3:** Можно ли отменить примененный фильтр?

**Ответ:** Да, можно отменить фильтр, нажав на его иконку повторно. Однако отмена применяется только к последнему примененному фильтру. Для полной отмены всех изменений рекомендуется не сохранять результат и вернуться к исходному изображению.

**Вопрос 4:** Сохраняется ли история обработки при переустановке приложения?

**Ответ:** Нет, история обработки хранится локально в базе данных приложения и удаляется при удалении приложения. Для сохранения обработанных изображений они сохраняются в галерею устройства, где останутся даже после переустановки приложения.

**Вопрос 5:** Работают ли AI-фильтры без подключения к интернету?

**Ответ:** Да, все AI-фильтры работают полностью оффлайн. Модели TensorFlow Lite загружаются вместе с приложением и выполняются локально на устройстве.

**Вопрос 6:** Какие форматы изображений поддерживаются?

**Ответ:** Приложение поддерживает все стандартные форматы изображений, поддерживаемые Android: JPEG, PNG, WebP и другие.

**Вопрос 7:** Можно ли обработать несколько изображений одновременно?

**Ответ:** Нет, приложение обрабатывает одно изображение за раз. Для обработки нескольких изображений необходимо обрабатывать их по очереди.

**Вопрос 8:** Как поделиться обработанным изображением?

**Ответ:** На экране предпросмотра AI-фильтра доступна кнопка "Поделиться", которая позволяет отправить изображение через другие приложения (мессенджеры, социальные сети и т.д.).
